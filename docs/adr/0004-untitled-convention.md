# ADR-04: Public untitled strings, "Untitled Vixio Film" and "Untitled Edition"

The first film ships publicly as "Untitled Vixio Film" with year 2026; the object ships as "Untitled Edition" with no year (none is publicly promised). This is the working film-industry convention ("Untitled <studio> Film" appears on slates, in trades, and in festival listings) and the art-world convention for editions (Untitled is a legitimate, common title for physical works). Both strings are titles, not apologies: they read as a label that announces work when it is real.

## Considered options

- "Untitled First Film": rejected; "first" leans on the label's newness rather than the work, drifting toward self-narration.
- "Untitled Short Film": rejected; "short" is category description on a tile, which the tile doctrine bans, and the Compass frames the label as producing "short films and films", so the format stays unstated until the title lands.
- "Object No.001" (from PLACEHOLDER-ASSETS.md interim copy): rejected outright; "No.001" is a banned internal codename. The asset doc's interim caption is corrected by this restructure.

## Consequences

RELEASE-NAMING.md carries 8 to 12 real title candidates for the founder; when a title is chosen, the swap is one field in lib/slate.ts. The single founder question of this run, if spent, is the title pick.
