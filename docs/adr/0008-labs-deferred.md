# ADR-08: Labs lane deferred from the public site

The Labs lane (Compass Track 2) does not appear on the site yet. The slate of record marks it optional; there is no public Labs artifact, no titleable work, and the lane's subject matter cannot be named publicly anyway (real-mythos references are restricted until the lawyer read). A third tile holding only the word "Labs" would dilute a two-work slate with a label instead of a work, which is the opposite of the tile doctrine.

## Consequences

The `labs` kind ships in the slate type (ADR-05), so the day a Labs release clears the craft bar it enters as one data entry framed strictly as R&D. Until then, Labs exists nowhere in public copy.
